## Sobre este proyecto y curso
Este proyecto es una plantilla inicial desarrollada con **Vite** y **TypeScript**. 

### ¿Qué se aprende en este curso?
En este curso aprenderás a:
* Configurar y utilizar **Vite** como entorno de desarrollo rápido y empaquetador moderno.
* Implementar **TypeScript** para añadir tipado estático, mejorando la detección de errores y el soporte de herramientas en el desarrollo.
* Estructurar módulos y componentes web modernos de manera limpia, eficiente y escalable.
* Gestionar dependencias y ejecutar scripts de desarrollo, construcción y previsualización de la aplicación.
